# Problem Statement

Managing campus transport manually can make student, bus, route and booking records difficult to maintain. The Smart Campus Transport System provides a simple Python-based solution for managing these records through a menu-driven terminal application.

## Scope

The system supports:
- Student registration and search
- Bus addition and viewing
- Route addition and viewing
- Bus booking for registered students
- Viewing booking details
- Transport reports
- Persistent JSON storage

## Target Users

The main target user is a campus transport administrator who needs a simple way to manage transport records.

## High-Level Features

1. Student Management
2. Bus Management
3. Route Management
4. Student Search
5. Transport Report
6. Bus Booking
7. Booking View
8. JSON Data Storage


## Course Alignment

The project provides more than three major functional modules, clear input/output, and a logical user workflow. It uses modular Python files, JSON persistence, validation, error handling and automated tests. The accompanying final report documents the required design artefacts and evaluation sections.
